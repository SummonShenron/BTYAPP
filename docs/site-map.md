# BTY Fitness Site Map

## Core Routes

- `/` - Home page
- `/programs` - Program overview
- `/consultation` - Consultation intake form
- `/book` - Public booking page with recurring schedule slots
- `/merch` - Merchandise page
- `/about` - About Madison page
- `/qualifications` - Qualifications and degrees page
- `/testimonials` - Testimonials page
- `/admin` - Madison admin dashboard

## Persistent UI Elements

- Top navigation links to the main public pages.
- The Book Session button in the navbar goes to `/book`.
- The coach portal link in the footer goes to `/admin`.
- The Sonic assistant widget appears on the site as a floating button and opens an embedded chat drawer.

## Assistant Behavior

- When users ask where something is, answer with the route name and a short description.
- When users ask how to book, point them to `/book`.
- When users ask for admin controls, point them to `/admin`.
