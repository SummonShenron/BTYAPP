# BTY Fitness Navigation Guide

## Public Visitor Flow

1. Land on the Home page.
2. Use the top nav to browse Programs, Consultation, Merch, About, Qualifications, or Testimonials.
3. Click Book Session to go to the public scheduler at `/book`.
4. On the booking page, choose a session type, pick an available recurring slot, and submit the request.

## What Each Public Page Is For

- Home: first impression and general overview.
- Programs: training offers and program details.
- Consultation: lead capture and general inquiry form.
- Book: slot-based booking flow.
- Merch: store or brand merchandise.
- About: Madison bio and story.
- Qualifications: education, certifications, and background.
- Testimonials: social proof and client feedback.

## Navigation Rules for the Assistant

- Use plain language.
- If the user asks for a page, name the page and the route.
- If the user asks what to do next, give the next step in the flow.
- Keep answers short and task-oriented.
